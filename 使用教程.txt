Tagger2 Inference Rebuild 中文使用说明
=====================================

【首次启动】

1. 支持 Windows 10/11 64 位。请先完整解压，不要在压缩包内运行。
2. 双击 setup.bat。目标电脑不需要安装 Python 或 Node.js。
3. 程序固定使用项目内的 runtime\python.exe，不修改系统 PATH，也不影响电脑原有 Python。
4. 启动脚本会自动检测 NVIDIA 显卡：检测到时安装 CUDA 依赖，否则安装 CPU 依赖。
5. 首次运行需要联网下载机器学习依赖，下载量可能达到数 GB，请勿中途关闭窗口。
6. 启动完成后访问 http://127.0.0.1:20000。

【以后启动】

依赖安装完成后双击 start.bat。setup.bat 也可重复运行；锁文件没有变化时不会重复安装全部依赖。

【更新 Git 检出】

从 Git 克隆的项目可双击 update.bat，同步 origin/main 的最新提交。更新器只执行 fast-forward；
存在未提交的受跟踪修改、分叉历史或 detached HEAD 时会停止，不会重置或覆盖本地工作。
更新成功后运行 start.bat，使依赖锁文件的变化生效。

发行 ZIP 不包含 .git 元数据，不能用 update.bat 原地更新。请从 GitHub Releases 下载新版，
确认 config、models、data_cache 和 data 等本地内容迁移完成后，再删除旧目录。

【便携环境目录】

runtime\python.exe             内置 Python
runtime\Lib\site-packages     新安装的 Python 依赖
models                         本地模型
data_cache                     模型下载缓存
data                           任务数据库、上传缓存和任务产物

移动整个项目文件夹即可迁移；删除整个文件夹即可卸载，不会留下系统级 Python 环境。

【本地模型】

在“本地模型”页面输入 Hugging Face 模型网址下载，或将已有模型复制到 models 目录。模型下载后会尝试自动读取预处理配置和最佳阈值配置。

【在线模型】

在“在线模型”页面新建 Provider，填写 API 地址和 API Key，然后点击“获取可用模型”。API Key 不会包含在发布包中，每台电脑需要自行配置。

【Tag Wiki：标签百科与中文检索】

侧边栏“Tag Wiki”页面提供本地化的 e621 标签百科，解决三个问题：这个 tag 是什么意思、
我想表达某个动作用什么 tag、这个 tag 要和什么搭配。

首次使用：打开 Tag Wiki 页面，点击“下载/更新 Wiki 数据”。程序会从 e621 官方导出下载
约 17 MB 的 wiki 数据包，导入本地数据库并自动下载嵌入模型（约 470 MB，仅首次）。
完成后即可使用全部查询功能。

1. 查含义：输入 tag 名（如 hug），显示中文摘要、英文原文、需要搭配的标签和相关标签。
2. 语义搜索：用中文描述画面（如“两个角色拥抱在一起”），返回推荐的 e621 标签和依据。
3. AI 问答：结合本地检索结果，用已配置的在线模型生成带来源的中文回答（需要在
   “在线模型”页配置一个可用的文本对话模型）。

中文摘要：点击“翻译中文摘要”可为高频标签批量生成结构化中文解读（含义/用法/搭配/注意
事项）。默认使用已配置的在线模型；不配置在线模型也可以用本机显卡跑本地模型，命令行执行：
runtime\python.exe scripts\translate_tag_wiki_local.py
任务可随时中断，再次执行会自动跳过已完成的页面。

快捷入口：标签管理页和工作台的标签胶囊上有一个小书本图标，点击即可弹出该标签的中文释义。
数据更新：e621 每天更新导出数据，在 Tag Wiki 页面重新点击“下载/更新 Wiki 数据”即可增量刷新。
命令行方式：runtime\python.exe scripts\build_tag_wiki.py --build（构建）、--translate（翻译）。

【批量输出目录】

原始图片文件夹：TXT/JSON 直接写在每张原图旁边。
任务产物：文件集中保存在 data\artifacts。
其他输出目录：保存到用户注册的可写目录，并按配置保留相对目录结构。

【手动指定 CPU/CUDA】

通常无需设置。需要覆盖自动检测时，在命令行执行：

set TAGGER2_TORCH_VARIANT=cpu
start.bat

或：

set TAGGER2_TORCH_VARIANT=cuda
start.bat

【常见问题】

端口 20000 被占用：关闭旧的 Tagger2 窗口或占用该端口的程序后重试。
首次下载失败：检查网络、代理、防火墙和磁盘空间，再运行 setup.bat。
CUDA 无法启动：更新 NVIDIA 驱动，或强制使用 CPU 模式。
页面打不开：确认启动窗口仍在运行，并访问 http://127.0.0.1:20000。

分享程序时，不要分享包含 API Key、访问 Token、私人图片或任务数据库的数据文件。
