# Tagger2 V1.10.5 发布说明

V1.10.5 是 Tag Manager 重构后的维护版本，重点修复数据安全、并发控制、批量编辑、编辑器状态同步和前端可访问性问题；Tag Wiki 延续 V1.10.4 的只读高频目录，不恢复已退役的嵌入向量检索或 AI 问答栈。

## 本轮修复

- **会话并发安全**：会话删除与索引、保存、批量、撤销/重做共享同一会话锁；刷新忙态可观察并返回稳定错误，不再静默跳过。
- **批量写入保护**：批量操作检测 sidecar 在索引后发生的外部变更，避免静默覆盖；保留部分成功操作的撤销日志与原子恢复语义。
- **编辑器可靠性**：保存成功后才更新 dirty 基线；保存响应带回新的 sidecar mtime，连续保存不会因缓存滞后误报冲突；无 sidecar/raw e621 内容不会显示可用的保存按钮。
- **批量范围契约**：过滤结果批量请求统一发送后端要求的 snake_case 字段，并对选中范围与过滤范围统一执行 2000 张上限预检。
- **错误状态**：图片详情和图片列表加载失败时显示可重试的错误态，不再永久停留在加载中或误显示为空结果。
- **键盘与无障碍**：标签自动补全支持上下箭头、Enter、Escape 和 `aria-activedescendant`；网格选择、只读 sidecar、撤销/重做后的选中状态均有回归保护。

## Tag Wiki

V1.10.4 引入的高频标签目录、分类浏览、模糊搜索、中文摘要与关联标签继续保持不变。目录由维护端 CLI 生成，发行包与前端只读；旧嵌入向量检索与 AI 问答功能不再随包提供。

## 版本元数据

Python 包、后端公开版本、前端 manifest 和 lockfile 根 package 均统一为 `1.10.5`。

## 验证说明

发布前运行后端 pytest、Ruff、mypy，前端 Vitest、ESLint、TypeScript/Vite、Playwright（桌面与移动项目）以及目录校验和发行冒烟。Tag Manager 专项测试覆盖 sidecar 并发、批量范围、dirty guard、冲突恢复、键盘网格和错误态。
