# Tagger2 V1.06 Release Notes

V1.06 publishes the V1.05 feature baseline under the 1.6.0 version scheme and
is the current release. Its code is identical to the `V1.05` tag except for
version metadata, so the complete changelog lives in
[V1.05_RELEASE_NOTES.md](V1.05_RELEASE_NOTES.md); the highlights are repeated
below. The pinned Dataset Workflow baseline is unchanged: the byte-identical
upstream ports (`caption_format/normalizer.py`, `caption_format/flat_txt.py`,
`stages/replacement.py`, `raw_e621.py`) and the frozen nine-field order are
exactly as before, guarded by the same port-manifest tests.

## Tag Manager (标签管理)

A BooruDatasetTagManager-style dataset tag editing workbench for e621 and
danbooru datasets; details in `docs/tag_manager.md`.

- Dataset sessions with background indexing, incremental refresh, grid
  browsing with tag-combination and sidecar-format filters, and three
  format-native editors (booru flat TXT, local tags JSON, nine-field standard
  JSON; raw e621 grouped JSON read-only). Saves are atomic writes guarded by a
  sidecar-mtime optimistic lock.
- Batch add/remove/replace (regex supported), a 20-step per-session
  undo/redo journal, tag-frequency statistics, cached thumbnails, and tag
  database autocomplete from the registered classify snapshots:
  `classify-e621-20260812-v1` (1,596,997 tags) and
  `classify-danbooru-20260902-v1` (140,782 tags / 29,636 aliases).

## Bilingual tags, separator toggle, NL translation

- **Offline Chinese dictionaries** ship in `resources/tag_translations/`:
  310,617 Danbooru entries and 68,399 e621 entries plus a 297-entry curated
  e621 glossary. Every tag surface renders the English name with its Chinese
  name, toggleable with 双语显示; lookups are case- and separator-insensitive
  and a missing dictionary degrades to English-only instead of failing.
  `scripts/build_tag_translations.py` regenerates them deterministically;
  sources and licenses are recorded in `MANIFEST.json` and the directory
  README (two of the merged sources declare no license; rebuild with
  `--sources amenorira` for an MIT-only dictionary).
- **Underscore / space toggle** governs both display and what is written back
  to the sidecar, matching BooruDatasetTagManager. `nl` and single-value
  fields are never restyled; filters compare on a normalized key so either
  spelling matches.
- **NL translation via a configured online model** through
  `POST /tag-manager/nl/translate`, applied only on an explicit 替换 NL.
  The provider picker lists only enabled providers that hold a credential;
  with none configured the route answers `409 nl_translate_unavailable`.

## Correctness, performance, refactoring (V1.05 baseline)

- Workflow NL adapter event-loop leak fixed; image-generation family
  inference resolves prefixed proxy aliases in `auto` mode; the unsafe
  pickle fallback is tightened; silent failure paths now log tracebacks.
- Blocking work moved off the event loop, DNS validation cached, job
  counters incremental, provider cache LRU-bounded, caption batching.
- `pipeline.py`, `workflow/api.py` and `main.py` split into focused modules;
  shared helpers consolidated into `common.py`.
