# Tagger2 V1.10.2 发布说明

V1.10.2 是一次版本元数据与发行准备版本，承接 V1.10/V1.10.1 已落地的 Tag Manager、Tag Wiki 与工作流能力；本版本不宣称新增未实现的业务功能。

## 本轮功能范围

- **Tag Manager**：提供数据集会话、虚拟化图片网格、标签过滤与统计、TXT/标准 JSON/九字段 Anima JSON 编辑、批量添加/删除/正则替换、撤销/重做、mtime 乐观并发保护和原子 sidecar 写入。支持 e621/danbooru 标签库自动补全、中英双语显示、下划线/空格风格切换，以及在已配置在线模型时翻译缺失标签和 NL 字段；raw e621 分组 JSON 仍为只读。
- **Wiki/tag 检索**：Tag Wiki 支持 e621 与 Danbooru 两个独立 profile；可查页面含义、中文跨语言语义搜索和基于检索内容的在线 AI 问答。Tag Manager 与工作台的 Wiki 抽屉跟随当前 profile。Danbooru 语料通过官方 JSON API 抓取，支持断点、增量导入和删除同步；构建完成的两个 SQLite 快照可随包提供。嵌入模型仍按需下载，未随包包含。
- **CLI/CI**：Tag Wiki 的构建、状态、翻译及 Danbooru 抓取可通过 `scripts/build_tag_wiki.py`、`scripts/fetch_danbooru_wiki.py` 等 CLI 使用；资源 manifest、指纹校验与按需资源获取策略保持不变。发行门禁继续覆盖版本元数据、构建产物与资源策略检查。
- **测试**：保留后端 pytest、前端 Vitest、Playwright、Ruff、mypy、ESLint、TypeScript/Vite、固定上游端口校验和 workflow smoke 等既有验证范围；本版本本身只更新版本元数据与发行文档，未修改测试实现。

## 兼容性与限制

- Python 要求为 3.12；前端依赖使用锁定的 npm lockfile（lockfile v3）。
- 模型、`data_cache/`、OCR 运行时及其缓存不随基础发行包提供；分类快照和 tokenizer 等模型类 workflow 资源按 manifest 从 resources-v1 获取，也可预取或手工放入内容寻址目录以支持离线部署。
- Wiki 数据库快照可解压即用，但跨语言嵌入模型仍需首次构建时下载。中文摘要、AI 问答、在线标签/NL 翻译需要已配置的 Provider；没有可用 Provider 时不会伪造结果。
- 发布包不包含用户数据、任务数据库、日志、令牌或密钥。ZIP 用户应从新版 Releases 获取更新并迁移本地配置、模型、缓存和数据目录。

## 版本元数据

Python 包、前端 manifest 和 lockfile 根 package 均统一为 `1.10.2`。本次准备未修改业务代码、测试或发布脚本。
