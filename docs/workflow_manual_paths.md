# Dataset Workflow 手动目录

Dataset Workflow 的任务表单使用完整绝对路径，不再要求用户先选择根 ID
再填写子目录：

- `源数据集完整路径` 必须是已经存在的目录。
- `新数据集完整路径` 用于“生成新数据集”；目录不存在时，点击“检查设置”
  会先显示确认窗口，只有确认后才创建目录。
- “更新原数据集”模式不需要输出路径，系统会在提交前建立备份。
- 相对路径、盘符根目录、设备路径、`..`、源输出重叠都会被拒绝。

路径绑定接口只把用户输入转换为内部 `root_id + relative_path`，响应、作业配置、
事件和摘要不会回传绝对路径。重复绑定同一规范化目录会复用已有根记录。

资源维护仍保留根目录选择器，因为它导入的是相对于授权 `input` 目录的 CSV，
不是任务的数据集路径选择器。e621 新任务默认使用
`replace-e621-pass-drop-v2`；该资源将原指定索引的全部 `pass` 行转换为 `drop`。
